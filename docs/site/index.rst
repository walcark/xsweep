xsweep examples
================

A library of type cases exercising xsweep on synthetic remote-sensing and
radiative-transfer problems: varied sweep sizes, varied memory profiles, one
page per case with the equations it implements and the actual output. See
the `guide <https://github.com/walcark/xsweep/blob/main/docs/guide.md>`_ for
the concepts; this site is worked examples with real numbers.
